# 放學後的十分鐘｜陽奈 Galgame 企劃

以空崎陽奈為主角的《蔚藍檔案》二創長篇 Galgame 企劃，基調為甜甜的日常與酸甜青春。作品會以互動式逐節形式迭代，並按情節需求製作 Galgame 風格圖像。

## 專案內容

- `knowledge/plan.md`：願景、規格與路線圖
- `site/`：GitHub Pages 靜態企劃頁
- `.github/workflows/pages.yml`：推送至 `main` 時自動部署網站

## GitHub Pages

此專案使用 GitHub Actions 部署 `site/`。建立遠端 repository 後，請在 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**；之後每次推送到 `main` 都會自動更新網站。

## 聲明

非官方同人企劃，與《蔚藍檔案》官方及其權利人無關。角色與原作相關權利屬各自權利人。
