# 正式版與試玩版裝置 QA 清單

**目的：** 在真實手機與桌面瀏覽器驗證遊戲操作、存檔、閱讀、音訊與背景呈現。這份清單是人工驗收流程，不會取代 CI 的語法、資料、DOM、圖片與路線稿檢查。

## 測試網址

- 正式版： https://310111-design.github.io/hina-galgame/game.html
- 試玩版： https://310111-design.github.io/hina-galgame/testplay.html
- 角色素材預覽： https://310111-design.github.io/hina-galgame/character-preview.html

## iPhone Safari

### 畫面與觸控

- [ ] 直向開啟：舞台填滿可用畫面，對話框、選項、設定按鈕不被瀏海或底部安全區遮住。
- [ ] 橫向開啟：背景、角色佔位圖與對話框仍完整顯示，沒有水平溢出。
- [ ] 遊戲進行中旋轉裝置：版面重新適應，不會卡在舊尺寸。
- [ ] 點擊舞台空白處可推進；點擊選項、設定、存檔、日誌等控制元件不會誤觸推進。
- [ ] 連續快速點擊：打字機效果先完整顯示當前句，再進入下一句，不會跳過選項。
- [ ] 章節標題提示不阻擋觸控，背景切換不造成畫面閃爍。

### 閱讀功能

- [ ] 慢／普通／快文字速度都能正常切換。
- [ ] 自動播放能前進，遇到選項時會停下等待選擇。
- [ ] 「跳過已讀」只跳過已讀內容，不會略過未讀劇情。
- [ ] 對話日誌可開啟、捲動與關閉。
- [ ] 文字大小變更後立即生效，重新載入後仍保留設定。

### 章節、存檔與重播

- [ ] 章節選單能看到並開啟全部章節，符合「全部解鎖」設定。
- [ ] 手動存檔六個欄位都可使用；覆寫前會要求確認。
- [ ] 重新載入後可讀取手動存檔，章節、旗標與路線狀態一致。
- [ ] 自動存檔在重新載入後能回到主線最近進度。
- [ ] 重播章節時可正常返回主線；重播進度不會覆蓋主線自動存檔或手動存檔。
- [ ] 試玩版的存檔與正式版分離；在試玩版存檔不會改變正式版進度。

### 音訊與背景

- [ ] 第一次觸控後 BGM 能正常啟動；切換場景時音量平順淡入淡出。
- [ ] BGM 與 SFX 音量可分別調整，設定重新載入後仍保留。
- [ ] 全域靜音能正確切換；解除靜音後音訊可恢復。
- [ ] 13 張 WebP 背景都能載入；D08F 書店咖啡角、D08P 學校庭院、D08R 雨天咖啡店場景與劇情相符。
- [ ] 對話框不會遮住重要場景焦點；背景細節沒有明顯色帶或壓縮破損。
- [ ] 全螢幕按鈕可用時進入全螢幕；若 Safari 不支援原生全螢幕，CSS 全視窗版仍可正常使用。

## 桌面瀏覽器

- [ ] Chrome／Safari 至少各開啟一次正式版與試玩版。
- [ ] 鍵盤方向鍵／Enter 等支援的快捷鍵不會在輸入框或對話框開啟時誤推進。
- [ ] 寬螢幕與縮窄視窗時，舞台比例、背景與對話框仍正常。
- [ ] 滑鼠操作與觸控操作的行為一致。

## 發現問題時記錄

請記下：裝置與系統版本、瀏覽器版本、網址（正式版／試玩版）、章節 ID、操作步驟、預期結果、實際結果；若方便，附上截圖。不要為了測試而清除正式版存檔，優先使用試玩版驗證新流程。
