> `knowledge/experience.md` 回傳仍在歷史段落截斷，工具只有整檔覆寫，無 append／patch。本補記由 plan 索引，待安全合併；不覆蓋主檔、不宣稱已完成主檔追加。

## 交付範圍

完成 B01→B02→B03 十八種局部分支組合的人工文本審校，記錄 [BOT-01～07](reviews/second-act-opening-transitions.md)，未修改正文或 runtime。開始時 routes 已配置三節逐句與分段同步，本輪保留並新增九個選項的字母／順序／label 精確同步，以及 2 正向／9 負向記憶體測試。三個固定 validators 並行通過：B01／B02／B03 分別 78／122／115 條正文 tuple。

## 方法與未來可使用範圍

1. **「或」後面的動詞也要查。** 前句承認互斥結果，後句「三種都留下」仍會把全部分支合併成玩家歷史。逐句檢查量詞及已完成動詞，而非只搜尋特定道具名稱。適用於所有有共通收束的 Galgame、任務結果與多結局敘事。
2. **交付物附帶版本。** 基礎範本、分支增補紙、共用清單不是同一版；前章新增保留原始資料，後章不能不交代就退回只有身份確認的舊規則。審校記錄「產生者／日期／版本／接收者／狀態」。適用於跨章公務、推理證物、任務交接及文件驅動劇情。
3. **規則學會了不等於習慣改好了。** 角色可以仍焦慮或忍不住回查，不必每章重學等待資料的意義。用「把昨天方法移用到新任務」呈現反覆練習。適用於慢節奏成長、日常連載與重複任務。
4. **精確時間同樣是分支道具。** C 專屬「明日四點」不能未經設定就出现在 A/B 共通回收；除追蹤物品，也追蹤約定與期限的來源。適用於倒數、約會、回查與跨日時間線。
5. **部分完成不是全部完成，也不是全部待補。** A 補欄位、B 改規則、C 指定來源應保留不同下一步；共通只談已確認部分與待回查部分，不一律貼回「待補資料」。適用於多解法任務與保留玩家選擇後果。
6. **選項文字是玩家承諾的一部分。** 對正文做展平／分段比較仍會漏掉 label 漂移；精確比較字母、順序、文字，不正規化標點來掩蓋差異。限定已知章稿格式，保留早期篇幅與成年篇規則分離。適用於漸進導入 Markdown/runtime 同步 CI。
7. **用記憶體負向案例測防線。** 檢查更換 label、重複／缺失／空白／未知字母、增加／重排選項，以及 runtime 順序／缺失資料；真實資料保持不動。適用於唯讀驗證器與不能安全還原大型檔案的工具環境。此測試只覆蓋選項比較函式，不冒稱整個解析器 mutation 覆蓋。
8. **不把預先存在的改動認領為新增。** 路線圖與實際程式可能不同步；先讀實檔，記錄哪些原已配置、哪些本輪擴充。適用於多工作區、續作代理與未完成文件回流。

## 限制及後續

- 本階段是審校與驗證器擴充，不是 BOT 修復、全篇審校或實機通關。A01～B03 展平共 957 tuple；三節 B 另查五段與選項，沒有全篇篇幅重算。
- 主經驗檔追加、runtime 安全修訂、美術精修仍受工具阻塞。無 Git status／fetch／merge 或 Actions／Pages 查詢，固定工具結果不能替代部署驗收。
- 固定驗證並行但不具背景測試 ID，沒有測試拖延。未修改 `.env`、原圖、透明草稿或遊戲正文。
- 內容下一批為 B03→B04→B05；若遠端仍非快轉拒絕，先解除同步阻塞，避免持續累積整檔路線圖衝突。
