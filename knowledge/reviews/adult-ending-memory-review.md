# 成年篇三個結局：條件回憶與共通段審校

## 範圍與結論

完整閱讀 `knowledge/flag-dialogue.md` 的 D08F／D08P／D08R 九組條件回憶，以及各結局的開場、A／B／C 分支、common 和路線結果。另核對 D01～D07 可累積的 `rest`、`teamwork`、`ordinary_day` 來源與各 `>= 2` 門檻的可達性。固定資料驗證確認來源文件與 runtime 的 21 組條件對話完全同步；本輪重點為語義前提及回憶與本章選項是否矛盾。

## 檢查結果

- **D08F 朋友線：** `rest` 回憶強調保留休息界線，與不預設固定見面頻率的 A／B／C 分支相容；`teamwork` 原句將寬泛累積旗標寫成玩家曾談過具體分工和界線，已改為一路以來願意聽彼此想法；`ordinary_day` 的普通日常記憶與分享近況、互助及彈性邀約一致。
- **D08P 搭檔線：** `rest` 原先在選項前說活動草案已排好緩衝，與 B 分支再次建議預留緩衝衝突；已改成陽奈理解先列清流程、再決定需要多少緩衝，實際安排仍留給本章選項。`teamwork` 改為合作中學會先說明再一起找方法，不預設曾確認特定分工表；`ordinary_day` 提前談自由閱讀空間，與共同活動前提及縮小規模的分支相容。
- **D08R 戀愛線：** `rest` 回憶支持放慢關係節奏，與 A／B 同意交往及 C 延後確認均相容；`teamwork` 移除「我記得你說過」的精確歸因，改為雙方一路以來願意談互相支持；`ordinary_day` 只回應普通日常，不預設 C 已經正式交往。
- 九組回憶均在選項前顯示，內容補充記憶而不決定關係路線或代替任何分支行動。旗標門檻能在 D01～D07 達成；未達門檻時，各章主要情節仍完整。
