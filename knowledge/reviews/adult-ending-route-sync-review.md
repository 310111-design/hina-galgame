# 成年篇結局分支與稿件同步審校

## 範圍

覆核 D08F 朋友線、D08P 搭檔線、D08R 戀愛線的稿件與 `site/game-data.js` 開場、A／B／C 分支、共通段、選項承諾及結局收束。已完成的九組條件回憶語義審校仍以 `adult-ending-memory-review.md` 為準；本輪補強結局正文同步與分支合流前提。

## 發現與修訂

- 三個結局先前只有總篇幅與單一路徑長度門檻，沒有固定保護稿件／runtime 的逐句、五段位置和選項文字同步。本輪統一 D08F／D08R 的段落標記，並讓 D08F／D08P／D08R 使用共通的五段及選項驗證。
- D08R 的 A 分支已約週末晚餐，C 分支只暫定普通見面並保留調整空間，B 分支則談聯絡方式、個人空間和分歧處理，沒有約定或傳送下一次見面日期。原 common 卻寫陽奈已傳來見面安排，並列出已確定與未確定的內容，對 B 路徑補造了不存在的行動。
- D08R 現改為陽奈看時間並收起手機；已約事項由雙方各自記下，未定事項留到彼此方便時再談。這樣保留 A／C 的暫定安排，也不假定 B 路徑已經排期。
- D08F 的三個分支可自然銜接書店後的散步；D08P 的共同活動建立在三個選項皆同意參與圖書館活動的前提上。本輪未因段落篇幅較長而任意刪除，後續完整遊玩仍需評估節奏與路線差異。

## 初次同步驗證與限制（後續共通段另有修訂）

`route-draft-targets.js` 現對三個結局啟用五段邊界、逐句文字／說話者／情緒、選項標籤及既有篇幅／路徑門檻。`validate-route-drafts.js` 通過：D08F 3,352 字元、路徑 2,645／2,689／2,654；D08P 3,279 字元、路徑 2,650／2,655／2,626；D08R 3,544 字元、路徑 2,582／2,667／2,853。

靜態同步只證明稿件和執行資料一致，不代表分支語義、演出節奏、瀏覽器通關、iPhone Safari 或完整歷史旗標序列已驗收。

## 2026-11-24 D08F 共通段的互動收束

複核朋友線 common 時發現，讀者先在公告欄拍下書籍交換活動資訊，後面又再次交代要各自核對時間及不必安排下次日期，與 C 分支「不設固定見面頻率」重複。改以陽奈回想兩人一路聊書，主動問玩家近期想讀卻還沒找到時間的書，接回她隨後提出互傳值得分享的內容。保留書店／社區活動與彼此邀請，減少一次排程原則重述，增加可直接延續對話的具體話題。

章稿與 runtime 同步，`validate-route-drafts.js` 重算為 D08F 3,338 字元、A／B／C 路徑 2,631／2,675／2,640；三條仍高於 2,500 字元參考值。這次是文本層面的改善，尚未做玩家盲讀、瀏覽器逐路通關或配音節奏驗收。

## 2026-11-24 D08R common 的重複主題精簡

D08R common 前一句已列出雙方如何保留工作、朋友、興趣與休息的個人重心，陽奈也明說「你的生活仍然是你的」；後面「一段關係不是把兩個人的生活合併……」再次以抽象語句概括相同主題，並緊接著又由旁白具體描述陽奈學會讓關係保有呼吸空間。刪去這句重述，保留角色對話、陽奈的成長回扣及後續散步分享，讓情感落點留在人物和行動上。

`validate-route-drafts.js` 確認 D08R 稿件/runtime、五段、選項、條件對話和篇幅同步：3,476 字元，A／B／C 路徑為 2,514／2,599／2,785。`validate-game-data.js`、`validate-game-shells.js` 亦通過。全篇最新重算見 `full-length-refresh.md`。此為局部文字修訂，不代表全篇 QA、盲讀或三路瀏覽器通關完成。

## 2026-11-24 D08P common 的重複關係總結精簡

D08P common 中，陽奈已直接說明搭檔不是互相承擔所有責任，而是共同判斷值得做的事並知道何時停下；緊接的旁白又以「清楚分工、互相尊重與共同選擇」抽象重述同一原則，最後另有實際交接及生活回歸各自手上的結果。刪除中間總結句，保留角色台詞和可觀察的合作收尾。

更新章稿/runtime 與正文統計後，D08P 為 3,238 字元，A／B／C 路徑 2,609／2,614／2,585；靜態稿件同步、路線篇幅與 game-data 驗證通過。此局部修改不代替活動全流程盲讀或瀏覽器通關。
