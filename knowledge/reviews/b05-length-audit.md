## 計數口徑

正文只取 intro／A／B／C／common 的 tuple[1]；含文字內標點與引號，不含說話者、情緒、章稿控制標記、metadata、選項 label／hint、節末記錄。條件對話獨立報告，不算入基準路徑。

同時輸出 UTF-16 code units（相容既有 routes 的 String.length）、Unicode code points，以及移除空白的 code points。B05 三者完全一致；一般章節若含 emoji、空白或組合字符，不可默認相等，code point 也不等於 grapheme／中文字數。

全分支原始總量＝intro＋A＋B＋C＋common，共通只計一次；去重總量對完整台詞文字精確 Set 去重，不忽略標點、不因說話者或情緒不同重複計算。單一路徑＝intro＋所選分支＋common，不去除實際重讀的台詞。tuple 是演出單位，不保證每條恰好只有一個語法句。
