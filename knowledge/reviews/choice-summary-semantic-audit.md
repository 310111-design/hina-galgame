# 2026-11-26 全章選項短摘要語義複核

## 範圍與方法

逐一比對 33 章的 99 個可見短摘要與各自完整選項文案，確認玩家不看完整長句時，仍能先辨認將採取的動作、談話主題或路線方向。檢查範圍是 `site/game.js` 的 `choiceSummaries`，不是 `site/game-data.js` 的 `choice.hint`；後者仍描述選擇對後續回憶的影響，兩者不可混為一談。

## 修訂

| 選項 | 原摘要 | 新摘要 | 原因 |
| --- | --- | --- | --- |
| A03 A | 留休 | 休息 | 原縮寫不自然，改用選項直接提出的休息方向。 |
| A04 B | 列事 | 清單 | 原縮寫生硬；選項要學生列出兩件待辦，以「清單」辨認動作成果。 |
| A05 A | 補休 | 休息 | 「補休」容易被理解成補償假期；選項實際是補上一段十分鐘休息。 |
| B03 C | 聽困 | 困難 | 原縮寫不自然；選項先詢問交辦對象遇到的困難。 |
| B05 B | 交核 | 初核 | 原縮寫不自然；選項的重點是由同伴進行第一輪核對。 |
| B06 C | 明日排 | 排程 | 原縮寫生硬；摘要應清楚表示安排明日回查項目。 |
| D02 C | 興趣 | 做得好 | 選項詢問最近工作以外做得不錯的事，不限於興趣。 |
| D05 A | 現在 | 認識 | 摘要更直接表示想認識重逢後的現在的她。 |

其餘 91 個摘要逐項檢視後保留：可直接對應選項的休息、交付、分工、回憶、場景、承諾或路線方向，或已使用合適的短詞。沒有改動任何完整選項台詞、回憶分類標籤、分支旗標、目的章節或存檔格式。

## 驗證與限制

- `validate-choice-runtime.js` 仍逐一確認全部 99 個選項各有且只有一個摘要，摘要長度為 2–3 個 Unicode 字元；另新增八項本次人工核對結果的明確回歸斷言。
- Pages workflow 的 18 個固定 validators、`node --check site/game.js`、`node --check site/chapter-intro.js` 與 `git diff --check` 全數通過；本次摘要變更尚待推送後部署。
- 本次是作者端逐項文字核對，不代表玩家盲讀或讀屏器實際體驗。摘要是否在每種字級／螢幕寬度都易讀，仍須以瀏覽器及真機驗收。

## 可重用範圍

適用於本作新增或改寫選項短標籤，以及其他以長選項搭配短預覽的互動小說。先將「當下可見摘要」與「影響回憶／路線的內部標籤」分開，再依完整選項人工校對動作與承諾；短標籤控制在 2–3 字，不以硬縮寫湊字數，並以獨立固定斷言保護已人工確認的文案。
