# 非結局條件回憶語義抽查

日期：2026-11-24  
範圍：P03、A02、B01、C01、D01 共 12 組 `flaggedIntro`；逐組對照條件門檻、此前可選來源、來源分支動作及條件台詞。D08F／D08P／D08R 九組結局回憶另見 `adult-ending-memory-review.md`。

## 判讀結果

| 章節／群組 | 可達來源與主線依據 | 語義判讀 |
| --- | --- | --- |
| P03 `rest`／`teamwork`／`ordinary_day` | 各自可由 P01 或 P02 對應選項取得；分支分別呈現停下來休息、共同分類／分工、離開公務談普通生活。 | 「先問力氣」「決策與過程可分開」「十分鐘不必帶計畫」均延續相應互動主題，沒有宣稱未發生的專屬道具或結果。 |
| A02 `rest`／`teamwork`／`ordinary_day` | P01／P02 的對應選項及 P03 的可選分支均能提供前置累積；A02 當下仍保留退件判斷與公務處理。 | 記起十分鐘、既有分工方式或公務外時間，與各自來源相符，沒有取代當章選項或解決退件主線。 |
| B01 `daily_checkin` | 可由 P03 C 的雙方可重提／協商約定，或 A06 各路共同落下的隔日預留時間取得。 | 「上次說好要留下的時間」有共同回收依據，且當章仍需重新排入安排，沒有宣稱休息已自動完成。 |
| B01 `teamwork >= 2` | 前置多個不同章節均有實際共同確認、分類、標註或交付步驟；兩個不同章節才可達門檻。 | 提早把第一輪確認列清單及及早分工，符合重複合作累積；台詞描述 B01 現況，不把特定早期表格說成已在此前交付。 |
| C01 `teamwork >= 2` | 需要此前至少兩個不同章節的合作選項；B08 common 已建立可供同伴使用的例行流程與交接條件。 | 回憶先前共同整理的規則並觀察同伴能獨立使用，與多次合作及目前交接情境相容；不是把某一次特定分支成果強加給玩家。 |
| C01 `self_rest` | 由 B08 A 分支增加；該分支實際安排不看公務訊息的時段，且 common 保留自主休息安排。 | 行程中留白、沒有立刻以新任務填上，對應實際選擇與共通結果。 |
| D01 `self_rest`／`ordinary_day >= 2` | `self_rest` 可由 B08 A 分支取得；普通日常須在不同主線章節累積至少兩次。 | 留白回憶與自主安排相符；普通日子台詞維持泛指多次日常，沒有聲稱特定一次活動或約定必然發生。 |

## 同步與限制

現行 `validate-game-data.js` 驗證這些群組的旗標門檻有足夠的不同章節來源；`validate-route-drafts.js` 比對條件章稿與 runtime。兩者都不會判斷回憶措辭是否精確描述所有可達歷史，本次人工覆核未發現必須修文的矛盾，因此沒有改動章稿或 runtime。

此抽查只處理 12 組非結局條件台詞的主題與來源，不窮舉所有可達旗標組合、不證明每位玩家都看過該內容，也不取代瀏覽器逐路遊玩或全篇語義 QA。新增條件對話時，應把「旗標累積所代表的寬泛傾向」與「明確發生過的單一事件」分開審核。
