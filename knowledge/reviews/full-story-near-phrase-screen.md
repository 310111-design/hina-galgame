# 全篇相鄰章近似台詞候選複核

日期：2026-11-24  
範圍：以目前 33 節 runtime 相鄰章的台詞為範圍，依說話者相同、字元三元組 Dice 相似度排序；僅將高相似候選帶回章稿閱讀，不把分數當成錯誤判定或自動改文依據。

## 人工覆核候選

1. **A02→A03「這件事是不是只能由我做」保留。** A02 以「請問我」將問題留給明天；A03 明說「我昨天問了自己」，句子直接回收前一章的自問，並推進到「有些只能由我判斷，大部分只要先確認規則」。字面相似是跨日回扣，後續答案有變化。
2. **C01→C02「不同格式的記錄」及交由別人判斷的疑慮保留。** C01 的不同欄位格式用於同日驗證交接條件，尚有兩個例外待回查；C02 是一週後的新測量資料，按相同時段比較後發現差異有合理原因。C01 的問題關心例外仍需有人判斷，C02 則檢驗新紀錄是否值得採用，角色在新的證據下將判斷延後，非同一事件重演。
3. **B03→B04「實際使用後再調整規則」保留。** B03 建立先用現有規則、遇到實際問題再補充的原則；B04 演出參與修訂的同伴用樣本試讀補充說明，並清楚區分次日由未參與修訂者獨立試走。前句是方法，後句是第一輪測試結果和下一個驗證步驟，沒有把隔日完整試走宣稱為已完成。
4. **C03→C04 的不安提問保留。** C03 屋頂談話問「如果我不在這裡，大家還會來找我嗎」，當下聚焦於未來與個人被需要；隔日下午整理舊資料時，C04 問「如果我不再負責，大家還會記得這些嗎」，轉而思考工作方法能否脫離她本人延續。後句由舊記錄與同伴使用新規則的場景引出，目標從個人位置移至留下的做法，屬角色問題深化。
5. **D07 C→D08F B 的靜音手機動作修訂。** D07 C 已以關閉通知、把手機放回包中呈現十分鐘屬於自己；D08F B 原本再次以幾乎相同的靜音／收手機動作表示不必隨時待命。朋友線的新增情境是兩人談話時收到訊息，將動作改為手機在布袋中震動、陽奈沒有立刻查看而先聽完對方說話，直接表現她在成年關係裡不必立刻處理普通訊息。朋友互相支持、不必待命的台詞與急事替代聯絡說明保留；選項、旗標及共通劇情不變。
6. **D01→D02 的學生時代句式保留。** D01 說目前的話與學生時代最後的話不同；D02 說多留十分鐘的習慣和校園時代相似，但沒有把空檔改成工作。兩處刻意以「不同／相似」各自標出成年後保留的習慣及改變，不是複製同一內容。

除 D07→D08F 手勢重複外，本批沒有其他需改動候選；本次只替換 D08F B 一條旁白，沒有改變選項、旗標、路線或結局結果。

## 驗證與限制

`validate-route-drafts.js`、`validate-game-data.js`、`validate-full-length-summary.js` 及 Pages workflow 全套檢查通過後，記錄同步後的 commit、Actions run 和 Pages HTTP 狀態。原候選盤點的文件提交 `6770597`／run `45361169906` build／deploy 成功；本次 D08F 稿件／runtime 修訂部署證據待推送後補入。這些檢查不等於三條結局路線實機通關或玩家盲讀。

這是相鄰章、同說話者的候選排序與人工上下文閱讀，不涵蓋同章或非相鄰章近義重述、不窮舉所有條件旗標／分支組合，也不代表全篇玩家盲讀、語氣朗讀或瀏覽器通關。字元三元組不能理解語義；角色、情境、時間間隔及後續行動才是保留或修改的判準。
