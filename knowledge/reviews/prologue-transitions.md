## 發現、修訂及殘留界線

### PRT-01｜P01 C 合流仍殘留辦公室限定（已修訂）

- **章稿與 runtime 證據：** C 到屋頂後說「她沒有提議回辦公室」，共通段卻仍有「夕陽正從百葉窗後完全沉下去，辦公室只剩桌燈和杯壁中未散的熱氣」及「但陽奈收起公文時的動作」。沒有交代人物回室或攜帶公文。
- **影響：** P01=C 的所有後續路徑；即使 P02 隔天自然回到辦公室，也不能倒補前一天共通段的動作。
- **修訂：** 將共通段夕陽、人聲與熱飲描寫改為不指定房間的環境變化；未完成公務改為明日續辦，移除桌面文件及返回辦公室的動作假設。C 路線仍留在屋頂至該節結束。

### PRT-02｜P02 A 把前一天室內休息寫成必經事件（已修訂）

- **章稿與 runtime 證據：** 「昨天的時候，我一直在確認時間是不是到了」及「這個地方不再只是昨天用來休息的例外」。
- **反例：** P01=B→P02=A，前一天是分擔文件而非在此休息；P01=C→P02=A，前一天休息在屋頂，不是當前辦公室。P01 A 也只明寫到時提醒，沒有反覆確認的具體演出，因此不把『一直』視為已逐句證實的回憶。
- **修訂：** 改成「今天我想試著不一直確認時間，先把這十分鐘留給自己」及「這裡也可以留出一段休息的時間」，不要求任何 P01 路徑先演出室內休息。

### PRT-03｜P02 B 無條件引用『昨天的方式』（已修訂）

- **章稿與 runtime 證據：** 分支首句「今天沒有需要由我親自決定的急件。可以試試昨天的方式。」
- **反例：** P01=A 或 C→P02=B，前一天未進行分工，P01 共通也沒有教會分類方式。只有 P01=B 的先前協作能支持這個指涉。
- **修訂：** 對話改為當日重新分類「需要我確認」與「能一起處理」的項目，不再依賴 P01 曾選分工；P02 選項標籤同步改成當次的「休息／分工／日常」，允許玩家自由換選項。

### PRT-04｜P02 B 兩欄清單突然出現中間欄（已修訂）

- **章稿與 runtime 證據：** 先「畫出兩欄」，定義左欄與右欄，接著說「如果不確定，就寫在中間那一欄」，稍後仍稱「兩欄之間」。
- **影響：** 每條進入 P02 B 的路徑；與前章旗標無關，不能用条件回憶修正。
- **修訂：** 保留兩欄；不確定的項目先記在便箋下方，等雙方確認後再歸類，保留陽奈的決策責任。

### PRT-05｜P02 C→P03 的回室交代不夠確定（已修訂）

- **章稿與 runtime 證據：** P02 C 結束於屋頂；common 把收杯寫成「收進桌邊，或放回紙袋，或帶回辦公室的隔夜位置」。P03 開場已收桌上便箋、觸碰桌面，沒有明寫人物返回。
- **判定：** 第三個『或』可以理解為屋頂分支帶杯回室，因此不是確定的瞬移硬矛盾；問題是散文並列替代路徑，没有把返回動作明確綁定 C。
- **修訂：** P02 C 明寫點心後帶杯沿走廊返回辦公室、放回桌邊並確認物品；共通段改為杯子已收妥，不再列出互相替代的三種位置。P03 仍接續同一天離校前。

### PRT-06｜P03『十分鐘』便條缺少明確建立動作（已修訂）

- **章稿與 runtime 證據：** P03 common 無條件拿起帶有「十分鐘」的便條；P01 B 只放下半張便箋，P02 A 寫「休息」、B 畫分工欄位、C 未寫便條，P03 B 只在便箋背面寫分工底線。
- **反例：** P01=C→P02=C→P03=A，全程沒有明寫製作該便條。這不是聲稱辦公室不能有便箋，而是主題物件的字跡首次出現時已被當成既有成果。
- **修訂：** P03 共通段明寫陽奈另取新便條，寫下「十分鐘」並夾到公文夾最上面；P03 B 另註明使用「分工用便箋」，不倒推來源或限定於 P02 A。

### PRT-07｜P01 稿末的 P02 選項與實際 P02 不一致（已修訂：文件導航）

- **章稿證據：** P01 `【選項：P02】` 是 A「下次也來分擔一次工作」、B「約定只談今天沒有完成的心情」、C「提議一起找一個真正的休息時間」；P02 正文和 runtime 的 A／B／C 則是休息、分工、日常。P01 頁首又用 P02-A（休息）、P02-B（分擔）、P02-C（屋頂）描述目前章內分支，容易與下一節混淆。
- **runtime 界線：** P01 實際只有當章的一組三選項；稿末這組不是額外可玩的選擇，沒有發現 runtime 多跳一層選項的證據。P02 稿末的 P03 三項則與 P03 當章選項一致。
- **修訂：** P01 頁首及稿末只列本章分支與下一章 P02，刪除看似額外選擇、但與 P02 真實選項不一致的預覽文字；P02 的選擇 label 已加進本批專用稿件對照。
