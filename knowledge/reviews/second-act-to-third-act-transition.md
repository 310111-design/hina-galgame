## B07→B08 九種局部組合

| B07 出口 | B08 A：走廊散步 | B08 B：喝水與空白 | B08 C：寫下明日第一步 |
|---|---|---|---|
| A：判斷與細節分開 | 可延續「不必每件事親自處理」；B08 休息是新一天的新安排 | 可沿用先不查看清單的原則；不等於已完成當日休息 | 可出現新的明日第一步，但不代表 A 曾留下該設備回查紙 |
| B：先喝熱飲 | B07 的熱飲休息與隔日 B08 的十分鐘不同日，可成立 | B08 的水杯不是 B07 熱飲，不應把兩次休息寫成同一次 | C 分支可建立設備回查第一步；A/B 不可共通引用此分支紙條 |

### B07→B08-01｜日期連接有標示，但 B07 的 BCT 日期問題會向下游傳遞（承接既有案）

B08 metadata 明確標示「隔日放學後」，正文亦稱「昨天留下的便條」，因此 B07→B08 至少有隔日錨點。B07→B06 的具體同日／隔日與十分鐘來源仍依 BCT-01／06 待修；若 BCT 採同日晚間收束，B07 的回憶應明確指當日已保留的十分鐘，而不可把 B05 的舊十分鐘再算作 B07 今日事件。

**推薦修稿基準：** 沿用 BCT-06：明確區分 B05 早些時候的十分鐘、B07 收工熱飲與 B08 隔日自主管理的十分鐘。B08 已寫清「隔日」不需要重寫；待 BCT 修訂時僅確認日期用語前後一致。

### B07→B08-02｜「昨日便條」的對象須分清楚（待釐清）

B07 C 分支另有「資料來源初步核對」便條；B07 common 全路徑新寫「喝完熱飲，不重新開檔」便條；B08 開場只稱「昨天留下的便條」，後文又說今天沒有熱飲，另寫一張新安排。這可理解為 common 的熱飲便條，但由於 B07 C 也有另一張便條，缺少名稱的指稱可能在該路徑歧義。

**推薦：** B08 開場用功能或內容辨識舊便條，例如明確指「不重新開檔」的收尾提醒；不要讓 B08 C 看起來必須把 C 分支的資料核對便條當作熱飲提醒。B07 common 的新便條確實全路徑成立，無須把 C 分支便條改成共通物件。

### B07→B08-03｜休息方法延續不等於物件／習慣已自動做到（待釐清）

B07 結尾留下熱飲收尾提醒；B08 開場先完成第一輪確認，直到放學後才安排十分鐘。這不是明確矛盾，因為隔日任務和休息計畫可以不同；但 B08 的角色進展是把不查看訊息的時間先寫下來，需避免暗示她隔日照著便條已自然改變。

**推薦：** 保持 B08 現有「今天沒有熱飲，但另寫新的安排」作為新行動；如修稿，可把它明確寫成她重新判斷今天可行的形式，而非昨天便條直接保證成功。此處不新增角色退步或新的旗標。

### B07→B08-04｜杯子及離場收束（局部觀察，與 BCT-07 分開）

B07 common 把杯子移至水槽旁、留下杯底水痕可以成立；B08 A 的自動販賣機飲料、B 的水杯與 B07 熱飲是不同場景物件，沒有證據顯示是同一杯。不要因為共用「喝」的描寫而假設道具必須連續存在。B07 的重複完杯／關門仍由 BCT-07 處理，本輪不重複記案。

## B08→C01：三條入口承諾逐路徑檢查

- **B08 A：** 玩家與陽奈走廊散步，未帶文件；十分鐘到點後查看普通資料補充，並重新放回手機。C01 隔日開始新的每週例行檢查，沒有要求 A 分支特有的物件或動作，入口成立。
- **B08 B：** 陽奈喝水、把「想到不等於現在要做」寫在便條。C01 沒有引用該句或假定她一定把便條帶到辦公桌，故無分支專屬物件依賴。
- **B08 C：** 陽奈只寫「先看設備回查資料，再判斷是否需要改流程」，C01 的例行設備檢查、資料日期缺漏及數值差異與此方向相容。但 C01 沒有明示時間是隔日早上、回查的是哪一份資料，也未回收「依回查再判斷流程」；目前可視為新一輪例行任務，不宜宣稱已兌現 C 的明確承諾。

### B08→C01-01｜設備回查承諾的履行時點與結果未明示（待釐清）

B08 C 寫下的第一步是先讀設備回查資料；C01 導入的是每週例行檢查，資料出現日期不完整及數值變化，之後被送回查證。這可能是新的一輪任務，也可能延續先前回查，文本沒有標明。若把兩者視為同一工作，先「看回查資料」後又發現需回查本身可成立，但需補清楚資料何時收到、先看見什麼、哪些項目仍待回查；若不是同一工作，就應避免讓玩家以為 B08 C 的明日第一步遭遺忘。

**推薦：** 最小橋接是在 C01 開場給出隔日時間錨點，說明先確認昨日約定的設備資料／結果；若資料尚未到，先記為等待狀態，再開始本週例行檢查。把本週檢查產生的兩項新問題與舊回查項目分開標記。不要讓 A/B 路徑被迫擁有 C 專屬的設備便條，可用「如果昨天有留下設備回查安排，先核對其狀態；接著處理本週例行任務」這種條件中性的承接，或只在 C 分支旗標下回收。

### B08→C01-02｜「團隊早上已完成第一輪」與玩家參與時間（待釐清）

C01 intro 說同伴在今天早上已按必要條件完成第一輪整理，陽奈則於任務日檢查資料；B08 的隔日章節標「放學後」，C01 未標具體時段。沒有矛盾的必然證據，但玩家前章剛與陽奈一起安排明日第一步，下一章直接跳到團隊已做完第一輪，會使承諾的可見結果不清楚。

**推薦：** 在 C01 metadata／開場標明「隔日早上交接、下午回到辦公室檢查」或其他清楚的單日時間順序；說明陽奈的角色是先確認必要條件後讓同伴做第一輪，而不是將玩家或陽奈漏出已約定的回查。若無意承接 B08 的設備項目，明示它已另行完成／等待回覆後再進入本週例行任務。

### B08→C01-03｜教學式總結重覆 B08 規則（節奏觀察，非硬矛盾）

C01 common 再次以「休息不是完全不看訊息／工作不是完全不管結果」對照界線，與 B08 common 的緊急例外、重新判斷主題相近。作為跨幕主題回扣可以成立，但應讓 C01 的新情境（團隊可以按不同格式完成第一輪）帶出新的證據，而非重講 B08 的抽象規則。

**推薦：** 若後續完整審校認定節奏重複，保留 C01 具體交接結果，縮短抽象複述，將焦點放在「格式不同仍可追溯」的新發現。不為刪減而擅自改變角色成長結論。
