# 立繪表情差分尺寸校準

日期：2026-11-24

## 發現

`site/game.js` 的 13 張表情差分全為 896×1200 RGBA，但透明畫布中的人物剪影範圍不一致。來源 alpha bbox 的可見高度介於 1,039～1,155 px，人物底部介於 y=1,161～1,192。CSS 對所有圖設相同 `height`，因此畫面切換表情時人物外框雖相同，實際人物會忽大忽小，腳底也會跳動。

逐句 `spriteSpeak` 動畫只做數像素位移，沒有 `scale()`。問題來源是表情差分的 alpha 邊界，不是一般對話動畫。

## 校準方式

保留全部來源 PNG 和逐像素相同的 lossless WebP，不裁切或重繪素材。以可見高度 1,122 px、底線 y=1,176 為共同顯示基準，runtime 依每張圖片的 alpha 高度與底線計算獨立 CSS `scale` 和百分比基線位移。個別檔案仍按原有 WebP → PNG → SVG 次序回退；進入 SVG 回退時清除表情專用校準值。

## 驗證範圍

- `node --check site/game.js`：通過。
- `node scripts/validate-character-sprite-webp.js`：通過，檢查 13 張畫布校準與 fallback、逐像素來源規格及 CSS 使用校準值。
- 瀏覽器預覽一次呈現 13 張 WebP 差分；桌面模擬畫面的人物高度與腳底基線一致。
- `git diff --check`：通過。

桌面預覽與靜態校準不等同實機 iPhone Safari、不同 viewport 的正式遊玩或完整劇情 QA；這些仍未完成。刻意縮放目前不會由普通表情或逐字對話觸發；未來應以明確的逐句演出標記控制。
