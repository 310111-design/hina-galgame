# 第三幕中段 C03→C04→C05：分支道具、整理進度與最後任務

## 範圍與增量

完整閱讀 C03、C04、C05 章稿，人工核對兩組交界各九種局部分支組合。這不是十八次瀏覽器通關。C03 屋頂門／取外套的 TAT-06 仍未修，本批不重編結案；既有 C01～C06 共通審校為歷史記錄，不代表現版沒有問題。

程式增量為固定 routes 的 C04／C05 targets：正文逐句、intro／A／B／C／common 五段、選項字母／順序／label 對照。沿用 parser、fixtures、成年篇門檻與 B05 篇幅盤點，未新增 fixture。下列 TMT 是初次審校時的修訂工作單；2026-11-24 已同步修改並回核，狀態見文末。

## 十八種局部分支組合

### C03→C04

| C03 出口 | C04 A：曾幫上誰 | C04 B：先分完資料 | C04 C：想帶走什麼 |
|---|---|---|---|
| A：希望信任能換地方延續 | 從被信任轉向具體幫助合理；不可說昨天已回答所有自我價值問題 | 整理不要求先回答未來；B 的分完承諾仍須保留 | 昨天談的是信任，未產生三詞便條；紙張須在本章建立 |
| B：觀看操場合作 | 看見團隊自主不等於已列過自己幫助的人；當章追問有增量 | 觀察合作轉向一起分類合理，但不能合流時回到半途 | 操場事件未生成紙張；C04 C 可新寫，不能稱昨日便條 |
| C：口頭說還沒決定 | 未決未來可與具體回憶並存，不應強制找到答案 | 昨日沒有拿紙，不能把口頭答案當分類便條 | 昨日明寫「沒有拿出紙」，本章新寫三詞是新事件，不是拿回舊紙 |

九格都經 C03 common 的下樓及「明天見」。C04 為午後整理舊資料，接翌日合理但目前未明示。C04 A/B 無寫三词事件，common 卻收起三詞紙；不論 C03 選哪一條都不能補足此前提。

### C04→C05

| C04 出口 | C05 A：室內等例外 | C05 B：陪走第一區 | C05 C：說明起點 |
|---|---|---|---|
| A：回憶讓人可以開始 | 從他人可開始轉為不介入，動機自然 | 短暫同行不是收回控制；仍須寫退出與返室 | 回憶他人詢問起點不等於本組已說明，當章核對合理 |
| B：實際分類舊資料 | 舊資料分類完成不等於新任務完成；兩者須命名區分 | 分類與區域巡查不同，勿把 B 成果抹成共同未完成 | 不同格式允許可延續，卻不需把昨日分類重新做一輪 |

九格的 C04 common 均為舊表格留待回查、已不用資料待明日整理、關門與「明天再繼續」。C05 直接開始新例行任務，沒有說明兩項舊承諾如何交接。C05 common 沒有明指三詞便條，不能把桌角休息便條武斷認成 C04 C 的紙；應視為另一張待交代的時段提醒。

## 初次審校發現與修訂基準

以下「待修」標示是初次審校當時的狀態；各項後續結果見文末 2026-11-24 修訂與回核。

### TMT-01｜日序、舊資料待辦與「最後一次」的範圍（待釐清）

- **證據：** C03 收尾「明天見」；C04 午後整理，指示已不用資料「等明天一起整理」，將舊表格列待回查，最後說「明天再繼續」。C05 開場只有日期通知、例行任務，沒有承接舊資料，也未說明為何這是最後一次。
- **判定：** 日序省略不是已證實的時間矛盾，未提舊表格也不證明它被丟棄。但目前讀者無法區分延期、交付和遺忘。「最後」不可推成全校從此無公務或官方畢業日期。
- **推薦：** C04 設為屋頂談話翌日下午；C05 再翌日，intro 簡述舊資料由指定職責的同伴按分類續理，表格改版另留負責人與期限。將「最後」限定為本次共同協助安排的最後一輪，後續例行公務仍由團隊接手，不新增具名原作角色或官方時間線。
- **驗收：** 昨日承諾→今日交付／處理狀態清楚；三路都能接續，沒有把「交付」直接當「已完成」。C05 末段突然出現的「明天才需要判斷的資料」須命名為下一輪待辦，與當日已補齊欄位分開，不必強行等同舊表格。

### TMT-02｜幕次與校園篇編輯語進入正文（待修）

- **證據：** C04 開場「第三幕的工作沒有突然變得輕鬆」；C05 common「這是校園篇裡最後一次以這種方式共同處理例行任務」。本輪逐句對照通過，兩句在 runtime 亦存在，不只是 metadata。
- **推薦：** 分別改為事件內的「這幾天的工作」與具體共同協助安排；幕次保留在標題。第三人稱旁白不是不得概括，而是避免用製作分篇取代故事內時間因果。
- **驗收：** 同步章稿與 runtime；與 TAT-02 同類但不同章節，不因修其中一案便結案另一案。

### TMT-03｜C04 共通仍引用 C 分支專屬三詞紙（待修，高優先）

- **證據：** C 分支寫下「確認、交接、留下時間」；A/B 無此動作。common 仍有「陽奈拿起那張寫著三個詞的紙，夾進自己的筆記本」及「筆記本裡的三個詞」。C03 C 特別寫了沒有拿紙，不能補救來源。C04 C 的「看著那句話」也缺誰把問題寫下的動作。
- **歷史對照：** 主 plan 曾勾選 C04 此類問題已修；本次現版章稿與 runtime 同步通過，證明当前仍有分支限定引用，不能沿用歷史完成狀態宣稱無問題。無 Git 差異工具，不猜測是回歸還是先前修訂未完整保留。
- **推薦：** 把寫三詞、收進筆記本都留在 C 分支，並先交代她拿出紙、聽完問題後思考。common 改為回想「今天的談話與整理」，不引用紙張／三個詞，不替 A/B 無條件補做 C。
- **驗收：** 分別讀 A→common、B→common、C→common，道具都有來源；C 的文字選擇仍有專屬結果。需雙源同步，不單改 Markdown。

### TMT-04｜C04 B 已分完卻在合流回到一半，分類容器也不一致（待修／釐清）

- **證據：** B 選項「陪她把舊資料分完」，分支逐份檢查並分類；common 首句「舊資料整理到一半時」。B 保留類放新資料夾，common 又說最早表格沒放進「保留箱」，此前紙箱只指不再使用類。
- **推薦：** B 明確完成當前整批的初步分類；common 改為暫停手邊整理、單獨檢視最早那份表格，不聲稱三路都只到半途，也不替 A/C 補上 B 的全部完成結果。保留／回查用資料夾，停用類用紙箱；把「最後一份」限定為手邊已確認停用的一份，不擴大成所有待辦已清空。
- **驗收：** 分類／複核是兩個不同層級，B 的分完承諾不被撤銷；舊表格從手邊→桌面→回查夾→留室可追蹤，容器名稱不漂移。

### TMT-05｜C05 B 退出第一輪後的返室缺橋接（待釐清／修訂）

- **證據：** B 選項承諾確認交接後退出，分支最後在第一區交回表並說「遇到例外再叫我」；common 直接描述送回資料、桌面攤開。C 只說每人報告起點，未明寫出發。
- **判定：** 時間省略可合理涵蓋走回辦公室，不是必然瞬移；但可見的退出結果是這個選項的承諾，宜補明。
- **推薦：** B 末尾明寫離開巡查隊伍、返室等待；C 末尾讓各組帶表出發。A 已留室，不新增巡查或重返動作。common 使用首輪資料陸續送達，不依賴同行才知道的資訊。
- **驗收：** 三路共同落點為辦公室，B 確有退出，C 確有開始；不得用 common 強制 A/C 也走第一區。

### TMT-06｜C05 對前句的解釋忽略否定詞（待修）

- **證據：** 陽奈先說「這不是我一個人把事情做完」，再說「是大家知道怎麼一起把事情做完」。旁白卻解釋「前一句仍然把所有完成歸到自己的手上」，与前句的「不是」相反。
- **推薦：** 保留兩句角色台詞，旁白改為「前一句放下獨自完成的要求，後一句說清共同完成的方法」，不把她已否定的想法再當成當下主張。
- **驗收：** 逐句核對主詞、否定及指代對象；同步正文與 runtime。這是共同段問題，三路皆受影響，無需改選項旗標。

### TMT-07｜C05 休息餘額與手機留置的收工界線（待釐清／修訂）

- **證據：** 共通先說仍有原本預留休息，持續回查後說「今天的休息還剩下五分鐘」，沒有何時開始／用了多少的說明；隨後說今天到此、手機放抽屜、拿外套、門邊道別。若手機為私人聯絡工具，帶外套離場卻留機的用途不明。
- **推薦：** 把五分鐘明示為預留時段因回查而剩下的時間，接著實際用完這五分鐘再收工；不宣稱已享用完整十分鐘。通知由既有值勤交接管道處理，收工時把私人手機隨外套帶走而不開公務通知，不擅增一支未介紹的公務專機。若要寫另約補休，須明說，不能用當天未使用的時間充當已完成休息。
- **驗收：** 開始／結束／回查占用／實際休息分開列；A 的等待不自動當作此段休息，B/C 亦有共同休息落點。手機的持有人及位置可追蹤，不讓「不工作」等於失去所有聯絡。

## 角色與分支結論

C03 的接受未知→C04 的自我價值→C05 的交接驗證有層次；反覆不安不等於成長被推翻，不應為消除重複而寫成已徹底改變。三節校園關係仍以支持與合作為主，沒有需要新增戀愛承諾的理由。各節三個選項有不同體驗，但選項履行、共通前提與物件來源仍需以上修訂。

未窮舉全歷史旗標；game-data 的全組對照不等於人工驗證全部累積狀態。沒有重算全篇字數，也未為早期章節新設成年篇門檻。
