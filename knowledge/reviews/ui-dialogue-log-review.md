# 對話紀錄面板與捲動複核

日期：2026-11-26  
環境：公開 GitHub Pages `game.html`，Codex 內建瀏覽器，390×844 模擬 viewport。

## 檢查流程

- 初始主線載入於 P03 選項狀態。重新載入後打開對話紀錄，空狀態顯示「尚無對話紀錄。」；本次閱讀歷史不會從主線存檔位置自動還原。
- 透過章節選單重玩 P03。介面標示「章節重玩｜主線存檔不變」；閱讀至共通段並開啟紀錄，產生 11 筆可見紀錄。沒有選擇任何選項。
- 面板在 390×844 直向畫面中提供文字大小、速度、自動播放及音量控制，紀錄清單置於其下方的獨立捲動區。

## 觀察結果

- 紀錄項目包含章節與說話者，例如「P03 · 旁白」及「P03 · 空崎陽奈」，台詞以清楚分隔的項目呈現。
- 清單打開後自動定位至最新項目；向上捲動後可回看較早的台詞，滾動條亦顯示清單內仍有內容。
- 關閉紀錄並使用「返回主線」後，畫面恢復原 P03 選項，未改變主線章節或選擇。P03 重玩期間讀到的文字仍可能寫入瀏覽器已讀索引。
- 此次另在同一公開 P03 選項畫面確認左側只有「日常／分工／約定」純文字摘要，沒有圓框，選項列的黑紫底保留。

## 驗收界線

這是單一章節、11 筆紀錄及模擬手機直向的局部檢查；沒有驗讀屏器、真實 iPhone Safari、桌面／橫向尺寸、大字模式、超長紀錄，亦未測定對話紀錄是否應跨重新載入保存。初始空狀態屬實際觀察，不據此推定為產品缺陷，因目前需求只規定紀錄可開關、可捲動並標示說話者與章節。
