# 姓名、旁白與正文文字框分離複核

日期：2026-11-26

## 起因與修正

使用者回報，旁白文字看起來仍擠進姓名格，並要求姓名和對話正文分成兩個文字框。前一版雖已有 `#speakerName`、`#story` 兩個 DOM 節點，卻讓姓名欄絕對定位，並只替陽奈台詞顯示姓名；旁白／系統沒有對應標籤，正文則靠可捲動容器上方留白避開姓名位置。這種結構不足以確保視覺上是兩個分開的欄位。

本輪改動：

- 姓名欄標籤依資料類型顯示「空崎陽奈」「系統」；旁白姓名欄保留空白，不顯示「旁白」。
- 姓名欄改為正常排版流中的獨立框；正文段落另有獨立邊框及低透明底色，位於姓名框下方。
- 正文區保留自己的捲動範圍，移除以大段頂端 padding 模擬姓名區高度的做法，避免正文捲到固定姓名牌後方。
- 首次公開畫面抽查發現正文框的細邊太淡，因此加強為較明確的金色雙像素邊界與低透明紫底，仍可透出原背景。
- 對照旁白狀態時發現舊版 `game.js` query string 仍被瀏覽器快取，導致原先設定的「旁白」映射未載入；正式頁與試玩頁改用新的 runtime cache-buster，並由 validator 鎖定該版本字串。
- 使用者確認不需要「旁白」姓名；旁白欄位改為空文字但保留固定高度，避免正文上移。空姓名槽本身透明，正文框仍位於其下方。
- 選項提示與結局狀態維持清除姓名欄，由既有版型顯示。
- 更新 `validate-game-shells.js`，保護姓名標籤映射、姓名框正常流與可見邊框，以及正式頁／試玩頁共用殼層。
- 正式頁與試玩頁 stylesheet／runtime cache-buster 同步到 `dialogue-text-boxes-v4-20261126`／`speaker-labels-v3-20261126`。

## 驗收狀態

`node scripts/validate-game-shells.js`、`node --check site/game.js` 及 `git diff --check` 均通過。這些靜態檢查確認正式頁／試玩頁欄位、說話者映射、旁白空姓名槽、姓名框正常流、正文框樣式及 CSS／JS cache-buster。

首次部署 commit `f301995`、run [45836700352](https://github.com/310111-design/hina-galgame/actions/runs/45836700352) 曾在公開 A04 畫面顯示「旁白」姓名；依使用者後續指示改為留白。最終 commit `7ac73a3`、run [45837885426](https://github.com/310111-design/hina-galgame/actions/runs/45837885426) build／deploy 成功。沿用同一個 `testplay.html` 隔離存檔，重載後進入 A05，在 803×694 公開畫面看到姓名牌保持空白、正文「她只是看著便條，又看著桌燈。」位於下方獨立金邊框；姓名槽沒有折疊，刷新後存檔仍在 A05。這只確認一種桌面 viewport 及一條旁白；陽奈台詞新框樣式、手機 viewport、文字放大、長句捲動、iPhone Safari 與讀屏器仍待驗。

## 限制與後續

目前只修正 UI 呈現，沒有改動故事正文、存檔格式或正式主線存檔。完整跨裝置及讀屏器 QA 仍依 `knowledge/device-qa-checklist.md` 待辦執行。
