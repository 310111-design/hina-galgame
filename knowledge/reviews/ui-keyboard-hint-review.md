# UI 2.0 對話區鍵盤操作提示

日期：2026-11-24

## 發現

`site/game.js` 已支援 Enter／空白鍵推進對話，打字動畫中也可補完整句；但 `dialogueHint` 只寫明點擊畫面，鍵盤玩家無法從操作位置得知此功能。

## 修訂

正式遊戲及 testplay 的初始提示、繼續提示與打字中提示均加入 Enter／空白鍵說明；既有輸入處理不變。`validate-game-shells.js` 現在確認兩個頁面皆顯示鍵盤提示，且 runtime 持續處理對應按鍵。

## 驗證與限制

已執行 JavaScript 語法、game shell、遊戲資料、路線稿件及 `git diff --check` 檢查。這些檢查證明提示存在且與程式事件相符，不代替完整鍵盤路徑、瀏覽器 focus、螢幕閱讀器或實機 QA。

## 可複用範圍

局部操作提示應列出該狀態下真正有效的按鍵，並與事件處理保持一致；選項、逐字中、選單及文字欄位需分開描述。適用於本作其他閱讀控制、互動小說與 Web app 的鍵盤操作提示。
