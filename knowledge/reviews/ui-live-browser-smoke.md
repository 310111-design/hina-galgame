# Pages 遊戲頁瀏覽器 Smoke 檢查

日期：2026-11-24  
網址：https://310111-design.github.io/hina-galgame/game.html  
執行環境：Codex 內建瀏覽器（桌面瀏覽器檢視）

## 檢查結果

- 遊戲頁正常呈現作品標題、章節進度、場景背景、陽奈立繪、對話框及「跳過已讀」控制。
- 展開「功能」選單後，畫面顯示企劃首頁、章節選擇、對話紀錄與設定、存檔、讀檔、從序章重來及全螢幕等入口；選單覆蓋在舞台上方，仍可見角色與對話區。
- 按 Escape 後選單收合，焦點回到功能選單按鈕。
- 驗收期間沒有推進對話、選擇分支、切換音訊或執行存讀檔操作，避免變更既有遊玩狀態。

## 證據與限制

檢查時公開 Pages 最新內容為 commit 2bff500 的部署，Actions run 45364349199 成功。此 smoke 只驗證桌面內建瀏覽器中的當前開局畫面、功能選單和 Escape 收合；未逐一操作各選單子頁、逐字推進或測量長句／選項溢位。執行環境不是 iPhone Safari 實機，不能據此宣稱 iOS safe-area、動態工具列、觸控、鍵盤／輔助科技矩陣或其他裝置 QA 完成。UI 2.0 仍保留上述待驗收項。

## 可複用範圍

本作每次修改主舞台或工具選單後，可用此流程快速檢查正式 Pages 開局、控制入口、鍵盤收合與焦點回復；也適用於有自動存檔的互動作品，先做不會改變劇情狀態的控制檢查，避免把 QA 操作寫進玩家進度。
