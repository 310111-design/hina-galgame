# UI 2.0 對話紀錄面板焦點回復

日期：2026-11-24

## 發現

對話紀錄面板可由關閉按鈕或 Escape 收起，收起時設為 `aria-hidden` 並 `inert`；既有程式沒有把鍵盤焦點移出面板。焦點若仍在面板的「關閉」按鈕，該控制變成不可見／不可互動，使用者會失去明確的鍵盤位置。

## 修訂

`toggleHistory(false)` 統一將焦點移回常駐可見的「功能」選單入口，涵蓋關閉按鈕與 Escape 路徑；`validate-game-shells.js` 固定檢查此焦點回復行為。面板重新開啟時，既有流程仍將焦點移至面板內的「關閉」按鈕。

## 驗證與限制

JavaScript 語法、game shell、路線資料及 `git diff --check` 通過。結構驗證不等於真實鍵盤、螢幕閱讀器、焦點可見性或跨裝置 QA。

## 可複用範圍

對話框或側欄收起並設為 hidden／inert 後，把焦點送回仍可見且能重新開啟它的控制項；面板開啟時再將焦點移至內容內適當控制。適用於本作其他選單、存檔介面與一般 Web app 的暫態面板。
