# 背景圖素材

此資料夾存放遊戲場景背景圖。原始上傳檔與語意化別名均保留，請勿直接覆蓋原始檔。

## 現有素材規格

- 13 張使用者提供的原始 JPEG 已逐張預覽並完成初步場景分類。
- 每張原始 JPEG 約 0.13～0.27 MB，尺寸為 1376×768 或 1408×768。
- 每張另有語意化檔名別名（同一 Git blob，不重複儲存圖像資料），供遊戲背景映射使用。
- 另保留 `prefect-office-evening-v01.webp`，作為早期已壓縮的辦公室背景版本。
- 目前遊戲以章節 ID 對應語意化檔名；正式映射請以 `knowledge/asset-register.md` 與 `BACKGROUND_BY_CHAPTER` 為準。

## 新增背景流程

1. 保留使用者提供的原始檔名與檔案。
2. 預覽並確認地點、時段、光線、方向及文字安全區。
3. 建立語意化檔名，並在素材清冊記錄原始檔與別名對照。
4. 更新 `BACKGROUND_BY_CHAPTER`，並確認場景類型與 BGM profile 一致。
5. 檢查存檔縮圖、手機裁切、對話可讀性及缺圖回退。
6. 若單張檔案或整體載入成本變高，再評估 WebP／AVIF 轉檔；不要只因格式偏好而重複轉換小型 JPEG。

## 注意

- 背景只作舞台底圖，不要把角色、對話框或 UI 烘焙進圖片。
- 保留底部對話框與角色立繪的視覺安全區。
- 未經視覺驗收，不可只依上傳順序推測素材用途。
