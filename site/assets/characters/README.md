# 角色圖素材

此資料夾存放角色立繪與表情差分。

建議格式：WebP 或 PNG；保留透明背景；依角色與表情命名，例如 `hina/normal.webp`、`hina/smile.webp`。

原始參考圖請另外保存，不要直接覆蓋已整理的遊戲素材。
